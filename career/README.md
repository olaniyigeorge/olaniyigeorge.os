## Key files

- **profile.json** — your career profile: target role, experience, tech stack, salary range ($36k–$120k), tier preferences, must-have/nice-to-have skills, exclusion keywords. Both scripts read this.
- **job_boards.json** — 10 configured boards (Wellfound, RemoteOK, Ashby, LinkedIn email_monitor, WWR, HN Who's Hiring, YC Jobs, etc.) + Google Sheet schema (21 columns) for the tracking sheet `1n9GIu_pYAMKFHh9_QVaLkaZnzMjrkf7ufLhUkg-mXZg` (gid 1344067524).
- **base/base_cv.pdf** — the canonical base CV. Every tailored CV is derived from this. Do not edit directly; use cv_formatter.py.

## Automation

- **scanner.py** — runs daily 08:00 WAT. Reads profile.json + job_boards.json, checks each enabled board (RSS/API/email_monitor), deduplicates against the Google Sheet, appends new matches. Requires `gws` or `google_api.py` for sheet writes and LinkedIn email monitoring.
- **cv_formatter.py** — `python cv_formatter.py --job-title "<title>" --company "<name>" --job-text "<description>"`. Extracts base CV text, analyzes fit (keyword overlap, matched/missing skills), builds a tailored .docx in `versions/`, and saves a `_fit_analysis.json` next to it.

## What's in review/

Files moved here for your review — likely duplicates or older versions of things already in `cv/versions/`, `contracts/`, or `cover-letters/`. The canonical base CV is `base/base_cv.pdf`. Everything else in `review/` is flagged for you to confirm whether to keep, discard, or promote.
