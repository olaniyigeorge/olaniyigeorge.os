# Meta — Repository metadata

Documents about the OS itself, not about Olaniyi. Things that are about the repository, not the person.

## Contents

- [OS Completion Checklist](os-completion-checklist.md) — meeting reference for filling in the OS. Work in progress.
- [Worklog](worklog.md) — current session worklog. Fresh starts here each session.
- [Worklogs directory](worklogs/) — historical weekly splits. Each file = worklog-YYYY-MM-DD.md.

## Convention

If a document is about the repo (how to use it, how it's structured, checklists for filling it in), it lives here. If it's about Olaniyi (who he is, what he's doing, how he operates), it lives in `self/`.

## Worklog structure

- **Current:** `worklog.md` — fresh worklog for the current session. Has "Done", "Still to do", and "Backlog" sections.
- **History:** `worklogs/worklog-YYYY-MM-DD.md` — one file per session/week when the current worklog gets split off. Kept as history, still searchable.
- **Splitting:** when `worklog.md` grows too large, move its Backlog into a new `worklogs/worklog-YYYY-MM-DD.md` file, keep the session's Done/Still-to-do at the top of the fresh `worklog.md`, and carry any unresolved items into the new Backlog.
