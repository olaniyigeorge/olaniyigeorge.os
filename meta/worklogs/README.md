# Worklogs — Historical worklog splits

Each file here is a snapshot of a worklog at the time it was split off: `worklog-YYYY-MM-DD.md`.

- `worklog-2026-09-17.md` — the 2026-09-17 session. Full record of the OS reorganization + initial structuring of self/, projects/, skills/, meta/.

## Convention

When `meta/worklog.md` grows too large:
1. Move the Backlog section into a new `worklogs/worklog-YYYY-MM-DD.md` file.
2. Keep the current session's Done/Still-to-do at the top of `meta/worklog.md`.
3. Carry any unresolved items into the new Backlog.
4. Add the new file to this README.
