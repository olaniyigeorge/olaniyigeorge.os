## How to use this

- Before making changes to a project, read its `context.md` (e.g. `projects/koya-ai-automations/context.md`).
- Each project directory may contain additional documents (weekly notes, meeting notes, decisions, etc.) — check the project's directory for what's available.
- To add a new project, create a `projects/<name>/` directory with a `context.md`.
