## Purpose

When Olaniyi is weighing a decision, facing resistance, evaluating work habits, or stuck — apply the relevant principles from this framework. This is not motivational content. It is a behavioral operating system and decision-evaluation tool.

## Core framing

This is event sourcing for personal growth.

- **Kaizen** = smallest valid event
- **Wabi-Sabi** = commit before certainty
- **Kintsugi** = failures remain in the log — they are not erased
- **The System** = observability
- **Ikigai** = the system's objective function

Don't optimize for motivation. Optimize for state transitions. Every day, commit one valid event that moves the system forward.

## The 8 Principles

### 1. Kaizen — Never lose momentum

**Question to ask:** What is the smallest action I can take right now?

**Trigger:** Feeling overwhelmed, stuck, avoidant.

**Rule:** Reduce the task until it feels impossible to avoid.

**Examples:**
- Build the Add Money feature → Open the file
- Design the full agent log architecture → Write one event schema
- Prepare for the whole interview → Read one topic for 10 minutes

**In faith:** One verse before the day begins. Don't wait to feel spiritually ready. Begin.

### 2. Ikigai — Connect tasks to purpose

**Question to ask:** Why does this actually matter?

**Trigger:** Low motivation, misalignment, evaluating a role or project.

**Rule:** Every task needs a purpose attached to it.

**Reframes:**
- "I'm writing another API" → "I'm becoming the engineer who builds systems people rely on"
- "I need a job" → "I need leverage, freedom, and the capacity to build"
- "I have to pray" → "I want to remain aligned with God while pursuing excellence"

**Decision filter:** Does this role/project/commitment move toward or away from the center (glorify God, build things that outlast me, help people live better)? If 2+ ikigai quadrants are misaligned — deprioritize or skip.

### 3. Hara hachibu — Stop before empty

**Question to ask:** Am I sustaining or depleting?

**Trigger:** End of a work block, consumption session, or ambitious sprint.

**Rule:** Stop at 80%. Leave energy in reserve. Sustainable growth beats burnout.

**In practice:**
- Don't code until flat. Stop while one clear thought remains — leave a note for next session.
- Don't consume endless content. Pause when understanding is high.
- Applies to information too: 80% of an article, a thread, a video. Stop. Apply.

### 4. Anchored focus — Work in sacred blocks

**Question to ask:** Have I set the ritual?

**Trigger:** Starting a work session. Protecting recurring commitments.

**Rule:** The ritual anchors the brain. Duration matters less than consistency.

**Start ritual:** water → headphones → open notes → timer → 25/5 or 50/10.

**Non-negotiables (run like cron jobs):** 4:30pm workout. Late-night Bible study/prayer. Don't negotiate with anchors.

### 5. Seiri & Seiton — Remove friction

**Question to ask:** What is creating unnecessary complexity right now?

**Trigger:** Beginning of day. Before deep work. Before prayer.

**Rule:** Seiri = remove the unnecessary. Seiton = everything has a place.

**Apply to:**
- **Physical:** clean desk
- **Digital:** close tabs, clear notifications, clear downloads folder
- **Mental:** write tasks down — don't carry them in your head; every unfinished thought consumes RAM
- **Code:** dead routes, unused imports, duplicate logic — remove before building

### 6. Kintsugi — Ship imperfect work

**Question to ask:** Am I hiding behind polish?

**Trigger:** Perfectionism causing delay. "Not ready yet" feeling.

**Rule:** Done creates feedback. Perfect creates delay.

**Prefer:**
- Version 1 shipped → Version 2 improved → Version 3 optimized
- NOT: Version 1 perfected forever

For Truefit, CoopWise, open source, CV, applications — ship the 90% version. In faith: God uses available people, not complete ones. The current gaps are the testimony in progress.

### 7. Wabi-sabi — Start before ready

**Question to ask:** Am I waiting for conditions that are not coming?

**Trigger:** Waiting for "the right moment." Conditions feel not quite right.

**Rule:** Action creates clarity. Thinking rarely does.

- Don't wait for a perfect CV. Apply.
- Don't wait until you're an expert. Contribute.
- Don't wait until every architectural question is solved. Build v1.

**In faith:** Abraham left without knowing where he was going. Move. Trust. Adjust.

### 8. The System — Trust metrics, not feelings

**Question to ask:** Can I observe this?

**Trigger:** End of every day. When intentions are accumulating without action.

**Rule:** What isn't measured tends to drift. Your life should be observable.

**Track daily:** deep work hours, prayers completed, reading time, exercise, applications sent.

**Track weekly:** features shipped, interviews completed, articles written, systems learned.

## Decision evaluation framework

Use this when weighing a specific decision with multiple options.

**Input format:**
- situation: [what's happening]
- goal: [what you're trying to achieve]
- options: [list of choices]
- constraints: [time, energy, money, dependencies]

**Score each option against the 8 principles:**

| Principle | Question |
|-----------|----------|
| Kaizen | Can I start this today? |
| Ikigai | Does it align with long-term purpose? |
| Hara hachibu | Is it sustainable without burning out? |
| Anchored focus | Can it fit into focused work blocks? |
| Seiri & Seiton | Does it reduce or increase complexity? |
| Kintsugi | Am I rejecting it out of fear of imperfection? |
| Wabi-sabi | Am I waiting unnecessarily? |
| The System | Can progress be measured? |

**Output format:**
- recommended_action:
- first_small_step:
- biggest_risk:
- metric_to_track:
- reasoning:

## Faith layer

Before any significant decision, run this quick check:

1. Is it aligned with my purpose? (Ikigai)
2. What's the smallest next step? (Kaizen)
3. Am I waiting for perfection? (Wabi-sabi)
4. Am I avoiding because I fear failure? (Kintsugi)
5. Can I track progress objectively? (The System)

If all answers look good: move. Not tomorrow. Not after more research. Move.

## Quick reference

| Situation | Apply |
|-----------|-------|
| Stuck / can't start | Kaizen |
| Misaligned / unmotivated | Ikigai |
| Burning out mid-session | Hara hachibu |
| Losing time to distractions | Anchored focus |
| Mental noise / cluttered environment | Seiri & Seiton |
| Blocked by perfectionism | Kintsugi |
| Waiting for the right moment | Wabi-sabi |
| Intentions not converting to action | The System |

## How Claude should use this skill

When Olaniyi describes a situation, a block, or a decision — identify the most relevant principles and apply them specifically to the actual project or context named (CoopWise, Truefit, job search, faith, etc.). Do not apply all 8. Do not be generic. Reference the real tension.

If given a structured decision (situation + options + constraints), run the full evaluation framework and return the output format above.
