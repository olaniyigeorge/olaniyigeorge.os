Use as the top-level summary of how Olaniyi wants the OS and AI agents to work.

## What this repo is

This repository (olaniyigeorge.os) is Olaniyi's personal operating system and persistent knowledge base. It is the source of truth for context about him, his projects, his work, his decisions, his goals.

## Core principle

When a request depends on existing context, search the repository before answering. Do not invent context that isn't present in the repo or the current conversation.

## How agents should work here

1. **Read AGENTS.md first** — it has the canonical "How I want things done" section.
2. **Read the relevant skill** in `skills/<name>/SKILL.md` for the kind of work you're doing.
3. **Search the repo** for context before acting on anything about Olaniyi's work/projects/decisions.
4. **Read project context** at `projects/<project>/context.md` before working on that project.
5. **Be concise** — lead with the answer, no filler, no re-summarizing.
6. **Don't commit/push** unless explicitly asked.
7. **Don't touch secrets** — don't read secret files to find keys; ask if config is missing.
