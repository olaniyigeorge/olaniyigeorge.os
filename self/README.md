# Self — Who I Am & How I Operate

The foundational documents about Olaniyi: identity, mission, values, life direction, behavioral operating system, writing style, and professional profile.

These are living documents — subject to change. Update them when you learn something persistent about yourself.

## Contents

- [Identity](../self/identity.md) — Better Man Project, Personal Mission Statement, Core Values, Identity, Links.
- [Core Pattern & MVV](core-pattern.md) — the behavioral operating system: completion/visibility gap, identity shift, Q1 2026 vision, decision filter, operating rules, anti-vision.
- [Writing Style](writing-style.md) — how to write like me; how to avoid AI slop.
- [Profile](profile.md) — professional profile: current focus, work style, long-term goals, tech stack, interests.

## How to use

When an AI agent needs to understand who you are, what you care about, or how you operate:
1. Read `self/identity.md` first — mission, values, faith anchor, life direction.
2. Read `self/core-pattern.md` — the behavioral pattern and minimum viable vision.
3. Read `self/writing-style.md` — how to write like you.
4. Read `self/profile.md` — current professional focus, work style, long-term goals.

When you learn something new about yourself that's persistent:
1. Decide which file it belongs in.
2. Update that file. Don't duplicate.
3. If it doesn't fit any of the four, propose a new file in this folder.
